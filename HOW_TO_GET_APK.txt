TCG Restock Monitor MV0.05

This ZIP contains the Android source project, not a compiled APK.

To create the APK on a Windows PC:
1. Install Android Studio.
2. Open this extracted project folder.
3. Allow Gradle/Android SDK sync to finish.
4. Choose Build > Build App Bundle(s) / APK(s) > Build APK(s).
5. The APK will be created at:
   app\build\outputs\apk\debug\app-debug.apk

Once the GitHub repository is created, this project can be configured with
GitHub Actions so each MV0.xx release automatically produces a downloadable APK.
